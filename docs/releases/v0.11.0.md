Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮换、失败自动换号。**凭证只在本机处理，不上传任何地方。**

**升级后流量分配和 0.10.1 逐位一致** —— 这一版加的七个权重因子全部默认关闭，
关着的时候权重计算和上一版完全相等。想用哪个再打开哪个。

## 装 / 升级

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

已经装过旧版的，推一下更新即可（`bun update magpie-gptpool` + 重启）。**账号库不动**
（`~/.magpie-gptfree/`），provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。

## 先说一件观测到的事

上一版把上游的额度快照原样存了下来、故意不派生任何东西，就是为了先看清上游到底给
哪些额度项。线上实测（5 个号）返回的是：

| 额度项 | 剩余（最少 / 最多 / 平均） |
| --- | --- |
| `reason` | 5 / 50 / 16 |
| `image_gen` | 1 / 20 / 7 |
| `deep_research` | 5 / 5 / 5 |
| `file_upload` | 2 / 15 / 5 |
| `paste_text_to_file` | 3 / 3 / 3 |

**没有 `text_gen`，也没有 `other_tool`。** 所以「哪一项算普通对话的额度」是个需要
你自己判断的问题 —— 插件不替你猜，猜错的后果是把请求送进「`reason` 还剩 50 次、
但普通对话早就打不动」的号。

## 新增：调度策略（默认全关）

设置页多了「调度策略」卡，四个开关 + 文本额度项选择 + S/A/B/C 权重。改完**下一次
请求就生效**，不用重启。

| 开关 | 作用 |
| --- | --- |
| 自动分级进权重 | 把自动推断出来的 S/A/B/C 乘进权重（关着时只展示） |
| EWMA 成功率加权 | 近期成功率高的号加权（0.6–1.4 倍） |
| 首字节延迟加权 | 首字节比号池中位快的号加权（0.6–1.4 倍） |
| 连续卡死降权 | 连续卡死的号 ×0.5 |

紧急回滚不用改文件，一条环境变量即可：

```
MAGPIE_GPTFREE_POLICY_EWMA=0
MAGPIE_GPTFREE_POLICY_TEXT_FEATURES=reason
```

## 新增：分级 S/A/B/C

自动推断 + 手工覆盖：

- **手工设的永远生效**（批量栏有「分级 S A B C 自动」按钮）。
- **自动推断的默认只展示**，面板上是灰色「仅展示」—— 因为推断规则还没在真实池子上
  校准过，先看清楚再决定要不要让它影响选号。
- 判据只用慢变量：成功率、近期成功率、首字节相对中位、连续卡死。**不含连续失败**
  （已经在权重里罚过一次）也**不含额度**（额度本来就是主导项）。
- 延迟用**首字节**而不是总耗时：实测成功出图要 27–32 秒，几乎人人都「≤45 秒」，
  拿总耗时分级区分不出好坏；首字节是 1.2–4.5 秒，差异是数量级的。
- 分级和「干净号加成」互斥 —— 两者都是「这个号靠谱」，同时生效等于加成两次。

## 新增：文本链路终于用上自己的信号

以前文本选号完全不看账本（刻意的：不能拿图片额度给文本加权）。现在看了，但只看
文本自己的：

- 额度只看文本额度项，**不读图片额度**；
- 判死只认「登录失效 / 人工标记」，图片的「从未成功」「三天未成功」「额度耗尽」
  都不算 —— 画不了图不代表答不了话；
- 冷却只看文本的限流时间。

直接效果：**图片额度 0、但还有对话额度的号，在文本链路上不再是权重垫底**，而是按
自己的额度正常参与分配。这是「复用账号资源」最实在的一块。

## 面板上的变化

- 账号行的状态列多了分级徽章（主色 = 已生效，灰色 = 仅展示）。
- 额度列多一行「文本 N」，只有真的从上游读到才显示。
- 设置页的「文本额度取哪个 feature」下拉项**来自账本里真实观测到的名字**，不是代码
  写死的。

## 修掉的两个坑

1. `Number(null)` 是 0，于是「额度未知」被当成「额度 0」，权重从 1 掉到 0.05 ——
   刚导入、还没检测过的号会被直接压到队尾。
2. 环境变量没设时被当成「设成 false」，导致面板上所有开关都显示「被环境变量锁定」，
   而其实一个 env 都没设。

## 升级注意

- **默认行为和 0.10.1 完全一致**，不需要任何操作。
- 想启用文本额度：设置页 → 调度策略 → 勾一个额度项 → 保存。建议先只勾一个，
  观察运行页的批次和账号表现再决定要不要扩。
- 账号如果从来没重新检测过额度，`limits` 是空的，feature 下拉会显示「还没观测到」——
  先去总览页点一次「全部检测额度」。
