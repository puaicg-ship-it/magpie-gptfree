Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮询、失败自动换号。**凭证只在本机处理，不上传任何地方。**

这是改名后的首个公开发布（`puaicg/magpie-gptpool`，基于上游 `yang0/magpie-gptfree`）。
插件内部仍然叫 `gptfree-pool`、数据目录仍然是 `~/.magpie-gptfree`，所以**从上游换过来不会丢号**。

## 装

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

装完点顶部「GPTFree号池」进去导号。账号文本一行一个，分隔符 `----` / `---` / `--` 都认：

```
邮箱----密码----2FA密钥
```

## 这一版有什么

- **批量导入**：TXT 文件或直接粘贴，导入前先在页面里改错行、看预览；导入后自动登录并把每个号
  同步成独立的 Magpie Provider（`gptfree-pool/...`），不弹浏览器、不开网页。
- **账号池六组视图**：可用 / 限流中 / 待检测 / 额度查询失败 / 需续期 / 已失效，可折叠、可搜索、
  可按额度或最近成功排序；批量检测额度与批量删除带**实时进度**（按 20 个一块发，显示 `20 / 45`）。
- **Token 状态说实话**：只认上游的真实证据（额度检测通过或成功出过图），本地解出 JWT 没过期
  不算数，所以只有 `Token 已确认` / `Token 未确认` 两种，没有含糊的「待请求确认」。
- **额度加权轮转 + 熔断**：按剩余额度做 smooth weighted round-robin，连续失败指数退避
  （10min → 1h）；额度打 0 的号等上游重置时间过后自动后台复检，复检不会触发 MFA。
- **四条判死规则**：授权连续失败 2 次（`auth`）、一次没成过且失败 ≥15 次（`never`）、72 小时
  没成功（`stale`）、人工标记（`marked`）。判死只是不再派活，账号还在池子里，重新导入或
  点「检测额度」通过即可复活。
- **账本按天记 400 天**：趋势图可按日 / 按周 / 按月 / 按年切，失败原因按错误码分类统计。
- **生图走 chat 接口**：`/v1/chat/completions` 里的图片模型自动桥到 `/images/generations`
  或 `/images/edits`，PNG 落盘后回一条带 markdown 图片链接的回复。

## 已知限制

- 只支持 ChatGPT **Web** 端账号（邮箱 + 密码 + 2FA），不支持 API Key。
- 上游对同一 IP 的注册/登录有风控，批量导入建议配代理（页面上的「HTTP(S) 代理」）。
- 额度耗尽后要等上游重置，插件不会绕过限制。
- 插件行为与 `v0.8.4` 一致：`v0.8.5` 只验证了版本号在 tag / CHANGELOG / 页脚 / `/api/health`
  四处是否同步，没有功能改动。
