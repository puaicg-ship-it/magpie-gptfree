Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮询、失败自动换号。**凭证只在本机处理，不上传任何地方。**

这一版是**可观测性修复**：上游用文字回绝生图时，终于能看见它说了什么。

## 装 / 升级

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

已经装过旧版的，推一下更新即可（`bun update magpie-gptpool` + 重启）。**账号库不动**
（`~/.magpie-gptfree/`），provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。

## 这一版改了什么

- **上游只回文字时，不再只有一个笼统代号**。生图请求被上游用文字回绝（既不是图片，也不是
  内容政策拦截）时，以前统一记成 `upstream_text_reply`，面板上只能看到这个词，原文在
  worker → 网关 → 账本一路被丢弃。现在：
  - 按关键词分成 **限流 / 额度用尽 / 封号 / Token 失效** 四类，分不出来的仍记
    `upstream_text_reply`；
  - 脱敏后的原文存进账号账本 `lastErrorMessage`，面板「上次失败」悬停时显示
    「上游原文：…」；
  - 成功一次后自动清空，和 `lastErrorCode` 同步。
- 面板给这几个新错误码补了中文标签和悬停说明。

## 兼容性

- 账本字段只增不减，旧数据照常读；`lastErrorMessage` 缺失时面板不显示原文那一行。
- provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。
