Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮询、失败自动换号。**凭证只在本机处理，不上传任何地方。**

这一版是**界面重构**：首页不再分「我的账号池」和「额度统计」两页，两张表合成一张，配色整套换掉。
功能一个没少，导入页原样保留，只是从首页降级成第二个 tab。

## 装 / 升级

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

已经装过旧版的，推一下更新即可（`bun update magpie-gptpool` + 重启）。**账号库不动**
（`~/.magpie-gptfree/`），provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。

## 这一版改了什么

- **首页 = 统计 + 列表**。打开插件先看到六个数字（当前账号 / 可用 / 限流 / 剩余额度 / 成功 / 失败），
  往下依次是调用趋势、失败原因、失效账号分类，最后是账号列表。不用再在两张表之间来回切。
- **一张账号表**。原「我的账号池」和「额度统计」的明细表合成一张：`账号 / 类型 / 状态 / 剩余生图额度 /
  成功·失败 / 最近检测 / 操作`。状态按六组（可用 / 限流中 / 待检测 / 额度查询失败 / 需续期 / 已失效）
  折叠分组，表头固定，滚动时不丢列名。
- **趋势柱顶直接标数字**。每根柱子上方写着「成功数 / 失败数」（绿的成、红的败），不悬停也能读；
  汇总行仍然给「生图 X 成 / Y 败 · 文本 A 成 / B 败 · 今天 N / M」。
- **导航收成两个 tab**：总览 / 导入账号。导入账号就是原来那套流程，一个字没改。
- **整套换配色**：主色从蓝换成**深青**（亮色 / 暗色各一套 CSS 变量）。品牌色只做品牌用，
  「成功 / 失败 / 警告」的语义色独立，不再和主色打架。
- **状态徽章不再重复数字**。Token 徽章说 Token 认不认（`Token 已确认` / `Token 未确认`），
  额度徽章说额度状态（`额度可用` / `已限流` / `冷却到期` / `需先续期` / `额度查询失败` / `额度待检测` /
  `已失效`），**还剩多少额度只看右边那一列**，同一行不再出现两遍。
- **前端收敛成一条数据流**：一次 `/api/stats` 拿全量快照 → 一次 `renderAll()` 渲染。切 tab 不发请求，
  搜索防抖 120ms，批量操作只重渲染表格。

## 已知限制

- 只支持 ChatGPT **Web** 端账号（邮箱 + 密码 + 2FA），不支持 API Key。
- 上游对同一 IP 的注册/登录有风控，批量导入建议配代理（页面上的「检测代理」）。
- 额度耗尽后要等上游重置，插件不会绕过限制。
- 界面在窄屏（< 720px）会逐级隐藏「类型 / 最近检测 / 成功·失败」几列，避免挤压账号名；
  手机上想看全，横屏或者把窗口拉宽。
