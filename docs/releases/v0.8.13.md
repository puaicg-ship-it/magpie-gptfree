Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮询、失败自动换号。**凭证只在本机处理，不上传任何地方。**

这一版是**面板结构的整理**：导入挪到导航右边、空号池给引导、配置类的东西收进一个「设置」页，
顺手补上了大家一直问的**清理日志**。

## 装 / 升级

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

已经装过旧版的，推一下更新即可（`bun update magpie-gptpool` + 重启）。**账号库不动**
（`~/.magpie-gptfree/`），provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。

## 这一版改了什么

- **「导入账号」挪到导航右边**，做成主色按钮，常驻在每一页的右上角。它原来是个 tab，
  但导入是一次性动作、不是「一直待着看」的视图，放在导航里会让人以为是个常驻页面。
  现在 tab 只剩 **总览 / 图片 / 设置** 三个；进到导入页时那个按钮自带一圈高亮，
  不会出现「整排 tab 全灰、不知道自己在哪」的困惑。
- **空号池有引导了**。一个账号都没有的时候，六个统计数字全是 0，看着像页面坏了。现在总览页
  直接给一张「号池里还没有账号」的卡片：大按钮 + 一句「先把账号导进来，号池才会开始轮询、
  检测额度、出图」+ 一行格式示例；账号表、搜索筛选、批量栏、失效分类一并收起，导入第一个号
  就全部回来。
- **导航上的图片计数默认显示 0**。以前没进过图片页时那里是「—」，看着像没加载出来。现在默认
  0，打开面板时后台静默取一次真实张数，所以有图也不会一直显示 0。
- **新增「设置」页**。回复格式原来在总览页工具栏，保留天数和清理时段原来在图片页头部 ——
  三个都是「配一次就不动」的东西，却分散在两个页面。现在合并成一页：**图片回复格式 /
  自动清理（保留天数 + 时段）/ 立即清理（早于 N 天）/ 清理日志**。图片页只留浏览、筛选和
  「删除选中」，头部一个「清理设置」直接跳过来。
- **新增清理日志（以前完全没有）**。自动清理是默默发生的：图打不开了，你分不清是被保留期
  清掉的、自己手滑删的，还是压根没生成成功。现在每次清理都记一条：时间、触发方式
  （自动清理 / 手动清理 / 删除选中）、删了几张、释放多少空间、失败几张、参数（保留几天、
  什么时段）。存在 `~/.magpie-gptfree/cleanup-log.jsonl`，一行一条、只留最近 500 条，
  设置页可以查看和清空。
- 日志**只记数量、释放空间和触发方式，不记文件名、不记账号** —— 文件名是随机 hash，没有
  信息量，记了只会让日志膨胀。没删到东西的清理（时段外跳过、本来就没有过期图）不记，
  免得日志被噪音淹掉。
- 底层小改：`deleteImages()` 现在先 `stat` 出文件大小再删，所以日志能说「释放了多少空间」；
  `pruneOldImages()` / `purgeOlderThanDays()` 的返回值也带上 `bytes`。新增接口
  `/api/images/cleanup-log`、`/api/images/cleanup-log/clear`，`/api/stats` 也带上了保留天数
  与清理时段（设置页不必先进图片页才拿得到值）。

## 已知限制

- 清理日志不记文件名（见上）。要查「具体哪张被删了」只能从图片页的剩余列表反推。
- 日志上限 500 条，超过就丢最旧的；不做归档。
- 手动「删除选中」也是「清理」的一种，同样会记一条（触发方式写「删除选中」）。
- 只支持 ChatGPT **Web** 端账号（邮箱 + 密码 + 2FA），不支持 API Key。
