Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮询、失败自动换号。**凭证只在本机处理，不上传任何地方。**

这一版补的是**图片的生命周期**：之前只会生成、只会按固定天数默默删，看不到占了多少、
也不知道哪张是哪天出的。现在面板多了第三个 tab「图片」，占用、产出趋势、批量清理都在里面。

## 装 / 升级

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

已经装过旧版的，推一下更新即可（`bun update magpie-gptpool` + 重启）。**账号库不动**
（`~/.magpie-gptfree/`），provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。
图片目录也没变（`/config/images`），旧图会直接出现在新页里。

## 这一版改了什么

- **新增「图片」页**（第三个 tab）：总张数 / 总占用 / 最早一张 / 最晚一张四个数字，加一张
  **近 14 天生成数量**柱状图（柱顶标数字）。
- **保留天数可配**：右上角 1–90 天，默认 7 天。改完立刻生效、不用重启；清理每小时跑一次。
  环境变量 `MAGPIE_GPTFREE_IMAGE_RETENTION_DAYS` 仍然优先，设了面板下拉就置灰并说明原因。
- **手动清理**：列表按大小 / 时间排序，按日期区间筛选，分页每页 20 张、缩略图按需加载
  （1000 张也不卡）。选中支持三种：点复选框、**按住往下拖**连选、Shift 点另一行选一段；
  「全选筛选结果」会把**整个筛选结果（跨页）**一次选中，然后「删除选中」或「清理早于 N 天」。
- **删除是安全的**：二次确认（自绘弹窗，沙箱里原生 `confirm()` 会被吞掉）、文件名白名单 +
  路径前缀校验（挡 `../`）、单次最多 500 个、**逐条容错**——某个文件删不掉只跳过并报原因，
  不会整批失败。
- **缩略图走同源**：面板 CSP 只允许 `img-src 'self'`，外网 `/img/` 会被拦，所以新增
  `/api/images/file` 透传；`<img>` 发不出自定义头，这条路由不校验会话（端口只监听 127.0.0.1，
  同一批图本来就由 nginx 公开）。

## 已知限制

- 缩略图是**原图缩放**，不是另存的小图：图多时首屏只是「按需加载」，磁盘占用不会被缩略图省掉。
- 清理按文件 mtime 算，手工改过时间戳的图会跟着时间戳走。
- 日期筛选按**本地日期**分桶（`getFullYear/getMonth/getDate`），跨时区看到的分组可能和你预期差一天。
- 只支持 ChatGPT **Web** 端账号（邮箱 + 密码 + 2FA），不支持 API Key。
