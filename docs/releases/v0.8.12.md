Magpie 的多账号号池插件：把一批 ChatGPT 普号批量导入本机，后台自动登录、自动同步成 Magpie
Providers，按剩余额度轮询、失败自动换号。**凭证只在本机处理，不上传任何地方。**

这一版是图片页的两件小事：**换个看法**（列表 / 网格）和**换个时段清**（避开生图高峰）。

## 装 / 升级

Magpie → 「插件」→「发现」→ 底部输入框填：

```
https://github.com/puaicg/magpie-gptpool
```

已经装过旧版的，推一下更新即可（`bun update magpie-gptpool` + 重启）。**账号库不动**
（`~/.magpie-gptfree/`），provider id 仍是 `gptfree-pool`，已保存的模型名继续可用。

## 这一版改了什么

- **列表 / 网格两种视图**。图片页标题右边多了一个切换：列表省地方、适合核对文件名和大小；
  网格用大图、适合一眼找「上次那张」。切换不动数据 —— 选中状态、拖动框选、分页都共用同一份
  状态，切过去选中的那几张还是选中的。
- **网格里的选中更好认**：卡片本身是 checkbox 角色（空格 / 回车也能选），复选框浮在缩略图
  左上角；按住往下拖照样能连选一片，Shift 点另一张照样选一段。文件名允许折两行，
  不会截成 `mwhqawerr-00000000…` 之后认不出是哪张。
- **自动清理可以限定时段**。右上角「清理时段」选起止小时，默认 `00:00–24:00`（全天，
  也就是和以前一样）。想避开生图高峰就设成 `02:00–06:00`；**跨午夜直接选 `22:00–06:00`**，
  会自动按「晚 22 点到次日 6 点」算。
- **为什么值得限时段**：清理本身是 `unlink`（很快），但要先扫一遍目录（`readdir` + `stat`），
  上千张时在慢盘上能吃掉几百毫秒 —— 而它偏偏是**生图之后顺手触发的**，也就是高峰最频繁。
- **夜里没人用也照样清**：光靠「生图后触发」的话，设了时段反而等于设了个不生效的开关
  （没有生图就没有清理）。所以面板服务自己挂了一个 **15 分钟的定时器**，到点就清，
  不依赖有没有人生图。
- **手动清理不受时段限制**：「删除选中」和「清理早于 N 天」点了就执行 —— 你人在电脑前，
  没必要等到凌晨。
- 环境变量 `MAGPIE_GPTFREE_IMAGE_CLEANUP_WINDOW`（写成 `2-6` / `22-6` / `0-24`）优先于面板，
  设了面板下拉就置灰并说明原因，和其它两项设置一致。

## 已知限制

- 网格视图不设 `max-height`（卡片高度随窗口宽度变，硬卡一个值必然切出半行缩略图），
  20 张一页会把页面撑长一点，交给页面滚动。
- 清理时段按**本地时区**的小时判断，和「近 14 天」的分桶口径一致；跨时区看到的时段会不一样。
- 时段刚开的那一下最多晚一小时（清理本身有每小时一次的节流，避免反复扫目录）。
- 只支持 ChatGPT **Web** 端账号（邮箱 + 密码 + 2FA），不支持 API Key。
