01 批量导入账号

单批最多 100 条 · 可多次追加，累计支持 1000 个账号轮询
支持导入的账号格式规范（每行一条，分隔符兼容 ----、--- 或 --）：
格式 1 标准三字段邮箱----密码----2FA密钥 （自动后台 HTTP OAuth + TOTP 换取 Token 入池；写成 邮箱--密码--2FA 也认）
格式 2 带邮箱链接邮箱----密码----2FA密钥----https://mail.xxx.store/... （自动识别前三项登录，不主动请求链接）
格式 3/4 带 Token邮箱----密码----2FA密钥----eyJhbGci... （也兼容 5 段结尾附 refresh_token，优先复用、过期自动重登）
选择或拖入 .txt 账号文件（加载后可在下方直接编辑）
文件内容会直接填入下方文本框；若某行格式不对可直接改好后再导入
0 行有效文本

提示：可多次批量导入追加到同一个号池。密码、2FA 密钥、JWT 与邮箱链接只保存在本机内存和加密号池中，预览和状态仅显示脱敏邮箱。
